# Meme Generator

Add classic outlined meme captions to any image and download the result as a PNG. Drag to position, auto-wrap and auto-shrink, nothing uploaded.

**Live:** <https://meme-generator.slippylabs.com/>

## What it does

- Classic outlined block-caps captions on any image — Impact, Arial Black, serif or monospace.
- Drag captions to position; text auto-wraps and auto-shrinks to fit the width.
- Start from an uploaded picture or a blank canvas, then download the PNG.

## Run it locally

A static site. No build step, no package manager, no dependencies:

```
git clone git@github.com:slippylabs/meme-generator.slippylabs.com.git
cd meme-generator.slippylabs.com
python3 -m http.server 8000
```

Then open <http://localhost:8000>.
